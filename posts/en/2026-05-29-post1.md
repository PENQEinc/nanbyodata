In this release, we improved the UI/UX of NanbyoData to help users access information more easily according to their needs. Major updates include the addition of a Help page and a new search method using the complete disease list.

- Main Updates
  - Statistical information on the top page can now be viewed and downloaded as detailed data lists.
  - A new Help page has been added to the NanbyoData portal site.
  - Users can now search from the complete disease list via the “Other Search Methods” section on the top page.
  - A summary page has been added for each disease, allowing users to easily review disease-related information.
  - The new “My Diseases” feature allows users to register and manage their selected diseases in a list.
