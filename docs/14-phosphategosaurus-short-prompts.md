# ホスファテゴサウルス 短縮プロンプト集

この文書は、画像生成ツールや簡易なイラスト依頼で使いやすい短いプロンプトをまとめたもの。

## 日本語プロンプト

低ホスファターゼ症の疾患キャラクター「ホスファテゴサウルス」。採用済みのステゴサウルスベース画像を参照し、その亜種としてデザインしてください。新しい別種のステゴサウルスを作るのではなく、同じシリーズ・同じ個体群のバリエーションとして見えるようにしてください。変えるのは配色、模様、背板の色味、表情の軽い差分だけにしてください。親しみやすく、落ち着きがあり、医療情報サイトに置ける清潔感のある印象。背景は淡くシンプル。

## 英語プロンプト

Create a mascot character for hypophosphatasia named Phosphategosaurus. Use the approved stegosaurus base image as the direct reference and design this character as a variant of that base, not as a completely new stegosaurus. Keep the same silhouette, line quality, eye style, and soft mascot shading. Change only the color palette, pattern accents, back plate color, and a small nuance in expression. The result should feel like the same mascot series and the same creature family. Clean, calm, memorable, suitable for a medical information website. Keep the background simple and light.

## 超短縮版

採用済みステゴサウルスベースの亜種として、低ホスファターゼ症の穏やかな疾患マスコットを作る。差分は色と模様と表情だけ。背景はシンプル。

## イラスト依頼用の一言

低ホスファターゼ症のための疾患キャラクターとして、採用済みステゴサウルスベース画像の亜種を描いてください。新しい別種ではなく、同じシリーズのバリエーションとして見えるようにお願いします。

## 使い分け

- しっかりした生成指示が欲しいとき: `13-phosphategosaurus-art-prompt.md`
- まず1枚試したいとき: この文書の日本語/英語プロンプト
- 入力欄が短いツール向け: `超短縮版`
