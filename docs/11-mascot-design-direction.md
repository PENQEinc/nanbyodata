# マスコットデザイン方針

## 方針転換

恐竜キャラクターは、学術図鑑風や半写実風ではなく、  
**シルエットで一目で分かるデフォルメマスコット** として設計する。

目的は、恐竜の正確な復元ではなく、

- 一目でモチーフが分かること
- 覚えやすいこと
- 疾患一覧に並んだ時に識別しやすいこと
- 当事者にとって見やすく、親しみやすいこと

である。

## 参考にする考え方

ゲームキャラクター、とくにポケモンのようなマスコット設計で見られる以下の原則を参考にする。

- シルエットだけで種別が分かる
- 特徴は少なく、強い記号を大きく使う
- 顔、輪郭、姿勢で印象を作る
- 細部よりも大きな形を優先する
- 色や模様の差分で個体差を作る

## シリーズとしてそろえるルール

- 最初にうまくいった1体を、シリーズの基準絵柄として扱う
- 次のベース種は、その基準キャラと同じ
  - 線の太さ
  - 塗りのやわらかさ
  - 目の描き方
  - 体の丸み
  - 背景の簡潔さ
  を共有する
- そのうえで、恐竜種ごとの記号だけを入れ替える

つまり「種は違うが、同じシリーズの仲間に見える」ことを重視する。

## 画像生成時の運用ルール

- 各カテゴリでは、まず最初にうまくいった1体を「シリーズ基準画像」として固定する
- 2体目以降のベース種は、毎回その基準画像を参照しながら生成する
- 指示文の中でも
  - 同じ線
  - 同じ塗り
  - 同じ目
  - 同じ丸み
  - 同じ背景処理
  を明示して、絵柄のブレを防ぐ
- 元の恐竜種の特徴は変えるが、絵柄自体は変えない

骨・関節系疾患カテゴリでは、現在のティラノサウルスベースをシリーズ基準画像として扱う。

## ステゴサウルス系で残すべき記号

ステゴサウルス系のベース種では、以下を最優先する。

- 小さい頭
- 低く太い胴体
- 背中に大きく並ぶ骨板
- 長い尾
- 尾のスパイク

この5つが、シルエットの段階で分かるようにする。

## デフォルメの基準

- 2頭身から2.5頭身程度
- 頭は小さめ
- 胴体は大きく丸く
- 足は短く太く
- 背板と尾スパイクは少し誇張する
- 顔は穏やかで、目は大きめにする

## ベース種の設計原則

ベース種SVGはカテゴリ共通の標準体とする。

- 配色は中立
- 模様はほぼ無し
- 表情は穏やか
- 種の特徴だけを強く見せる

ここでは疾患固有の表現は入れない。

## 5ベース運用

- 各カテゴリには、あらかじめ5つのベース種を用意する
- 疾患ごとのキャラクターは、その5種のうち1種を選んで亜種化する
- 先にカテゴリ全体のベース種を作り切ることを優先する
- 1疾患ごとにゼロから新しい種を作らない

骨・関節系疾患カテゴリでは、現在の想定ベース種は以下の5つ。

- ティラノサウルス
- トリケラトプス
- ステゴサウルス
- ブラキオサウルス
- プテラノドン

## 亜種の差分

亜種では、以下だけを変える。

- 配色
- 背板の形の微差分
- 模様
- 目元や表情のニュアンス

一方で、以下はしない。

- 症状の直接的な見た目化
- 痛みや欠損のイメージ化
- 当事者がつらさを連想しやすい表現

## 今回の実装方針

- ベース種ステゴサウルスSVGを、カテゴリの5ベースの1つとして整える
- 低ホスファターゼ症の亜種 `ホスファテゴサウルス` は、ステゴサウルス系ベースから軽い色差分だけで作る
- summary と my-diseases の両方で同じキャラクター定義を使う
