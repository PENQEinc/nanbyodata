# ステゴサウルス ベース種メモ

骨・関節系疾患カテゴリのベース種としてステゴサウルスを使う場合の、形状抽出メモ。

## 一目で分かる特徴

- とても小さい頭
- 低く横長の胴体
- 背中に並ぶ大きな骨板
- 四足歩行
- 後方へ長く伸びる尾
- 尾の先にある4本のスパイク

## キャラ化しても残すべき要素

- 頭は胴体に対して小さくする
- 頭より背板の方が目立つ構成にする
- 胴体は高すぎず、安定感のある低い形にする
- 背板は背中の中央線に沿って、連続して見えるように置く
- 尾は十分に長くして、後ろへ抜けるシルエットを作る
- 尾のスパイクは2対あると分かるようにする

## 避けたい表現

- 頭が大きすぎて別の恐竜に見えること
- 背板が少なすぎてステゴサウルス感が消えること
- 尾が短くて重心だけが大きく見えること
- 直立に近く、二足歩行のように見えること

## SVGでの設計方針

- 完全な写実より、まずは認識しやすい横向きシルエットを優先する
- 背板は大中小のリズムをつけて並べる
- 尾のスパイクは背景に埋もれないよう明度差をつける
- 亜種差分は色味、模様、背板の微調整に留める
